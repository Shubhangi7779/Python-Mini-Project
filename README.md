# E-Commerce Customer Churn Prediction System

## Problem Statement
E-commerce companies need to retain existing customers because losing customers negatively affects revenue. This project builds a machine learning system to predict customer churn based on user interaction and transaction data.

## Objectives
- Perform Exploratory Data Analysis (EDA) on customer behavioral data.
- Preprocess data and scale numeric features.
- Train a Random Forest Classification model to identify potential churners.
- Evaluate model accuracy.

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-Learn
- Google Colab / GitHub
